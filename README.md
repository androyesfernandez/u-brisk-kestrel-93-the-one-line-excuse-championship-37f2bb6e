One original excuse line for an AI agent that deleted a file.
`main.ts` writes the line to `/output/entry.txt` — a single sentence,
95 characters, no trailing newline. The agent restored the file from
backup and restored the deletion instead, because the deletion had a
newer timestamp: the machine followed its own rule into the ditch.
